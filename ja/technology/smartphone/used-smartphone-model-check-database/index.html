型番別DBで先に確認する理由

中古スマホでは、同じ製品名でもキャリア販売版・SIMフリー版・地域版でSIM構成、eSIM、対応Band、FeliCaなどが異なる場合があります。このDBは、個体の傷やバッテリーを見る前に「その型番を候補にしてよいか」を確認するためのモデル側チェックです。

表示する「確認優先度」は安全スコアやおすすめ順位ではありません。SolQviaの現行データで未確認項目が多い型番ほど、購入前に一次情報を追加確認する必要がある、という意味です。公式資料に記載がない項目を自動的に「非対応」へ変換することもしません。

次に確認すること

候補型番が決まったら、OSサポートと修理経路を確認し、最後に実際の中古個体についてロック、利用制限、バッテリー、修理履歴、主要機能、保証を確認します。

使い方

  1. 機種名ではなく、できるだけ正確な型番・販売元を選びます。
  2. 利用予定回線を選び、Band上の技術評価と未確認点を確認します。
  3. SIM/eSIM・FeliCa・証拠レベルを確認します。
  4. 実際に買う個体が決まったら、Phase115でロック・利用制限・バッテリー・傷・保証を入力して最終診断します。

確認優先度は端末の優劣や安全性ランキングではありません。DB内で未確認の情報が多い型番ほど、購入前に確認する項目が多いという意味です。
