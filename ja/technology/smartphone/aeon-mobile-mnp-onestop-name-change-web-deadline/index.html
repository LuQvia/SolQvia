通常解約を先に実行しない

電話番号を引き継ぐ場合、MNP転出が完了する前に通常解約を確定すると番号を失う可能性があります。まず現在の契約状態とMNP手続き可否を確認してください。

SolQvia独自診断｜イオンモバイルのMNPで名義が違う・ワンストップできないを4軸で切り分ける

このページでは「契約状態・転出方式・予約番号状態」を一括で変更せず、記事固有の4項目を順番に比較します。イオンモバイルのMNPで名義が違う・ワンストップできないでは、どこで条件が変わるかを記録すると、同じ症状でも設定問題・契約条件・仕様差を分けやすくなります。

確認軸見るポイント判断の目的
1. 転出元がワンストップ対象か申込画面で確認する変更前の値と、正常な条件との差を確認症状が出る条件を固定する
2. 予約番号方式なら残り10日以上あるか確認する変更前の値と、正常な条件との差を確認設定で直せる範囲か確認する
3. 名義が違う場合は同一住所条件と双方の本人確認書類を準備する変更前の値と、正常な条件との差を確認契約・サービス側条件を分離する
4. SIM到着後は切替受付時間内に開通手続きを行う変更前の値と、正常な条件との差を確認仕様差・非対応を最後に判定する

設定で直る範囲と、設定では直らない範囲

  • イオンモバイルのMNPで名義が違う・ワンストップできないの設定・手順側：契約・手続き状態で解決できる可能性が高い
  • イオンモバイルのMNPで名義が違う・ワンストップできないの仕様・契約側：回線種別そのものがMNP対象外、または転出先条件に合わない場合は設定変更だけでは解決しません。

この症状で残しておく記録

  • 契約中の回線種別と名義
  • 予約番号の発行/有効期限状態
  • 通常解約やSIM再発行など処理中の手続き
  • 転出先で選んだワンストップ/予約番号方式

SolQviaでは「イオンモバイルのMNPで名義が違う・ワンストップできない」について、公式仕様で確定できる条件と、実際の端末・契約画面でしか確定できない状態を分離します。特に「転出元がワンストップ対象か申込画面で確認する」と「予約番号方式なら残り10日以上あるか確認する」を確認し、仕様上の非対応を設定変更だけで直る問題として扱いません。

結論

イオンモバイルはインターネット契約でMNPワンストップに対応しています。予約番号方式でWEB申込する場合は有効期間が10日以上必要です。現在の契約名義と異なる名義で申し込む場合は、同一住所など公式条件を満たせば申込と同時の名義変更を受け付ける案内があります。

ワンストップなら事前予約番号を省略できる場合がある

イオンモバイルは2024年6月からインターネット契約のMNPワンストップ受付を開始しています。

予約番号方式のWEB申込は残り10日以上

有効期限が不足するとWEB申込条件を満たしません。

名義違いは条件付きで同時変更可

現在の通信会社の契約名義と同一住所に住む場合に限り、申込と同時の名義変更を受け付ける案内があります。本人確認書類は双方分が必要です。

SIM到着後の切替受付時間にも期限がある

利用開始手続きは原則9:00〜19:59で、有効期限前日は16:59まで。未実施の場合は期限前日17時以降に自動切替される案内があります。

解決手順

  1. 1
    転出元がワンストップ対象か申込画面で確認する
  2. 2
    予約番号方式なら残り10日以上あるか確認する
  3. 3
    名義が違う場合は同一住所条件と双方の本人確認書類を準備する
  4. 4
    SIM到着後は切替受付時間内に開通手続きを行う

それでも進めない場合

画面表示や契約状態は事業者側のシステムで変わることがあります。別の解約・SIM変更・本人確認・支払関連の処理が進行していないかを確認し、公式マイページに表示される状態を優先してください。公式ページにない原因を推測して操作を重ねるより、現在の契約状態を事業者サポートへ確認する方が安全です。
