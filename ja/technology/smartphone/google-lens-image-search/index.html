Googleレンズ・画像検索・画面検索

Googleレンズで画像検索する方法｜Android・iPhone・Chrome・保存写真の使い分け

Googleレンズは、カメラで目の前の物を調べるだけでなく、保存写真、Webページ上の画像、対応Android端末では画面上の画像や文字も検索できます。入口がGoogleアプリ・Chrome・Googleフォト・Safari・かこって検索で異なるため、目的別に使い分けるのが最短です。

まず結論：目的によって入口を変える

やりたいこと使いやすい入口
今カメラに映っている物を調べるGoogleアプリ / Chromeの検索バーからGoogleレンズ
保存済み写真を調べるGoogleアプリ / Chrome / Googleフォト。iPhone/iPadではSafariから保存画像を使う方法もGoogle公式に案内あり
Webページの画像を調べるGoogleアプリまたはChromeで画像を長押し → Googleレンズ
Androidの画面に表示中の物を調べる対応端末なら「かこって検索」
写真内の文字をコピー・翻訳Googleレンズのテキスト/翻訳機能

Googleレンズの画面やボタン名はアプリの更新で変わることがあります。SolQviaでは特定のアイコン位置を固定せず、Google公式が現在案内している入口ごとに説明します。

「Googleレンズ」「画像検索」「かこって検索」は似ているが入口が違う

Googleレンズは画像を使って検索する仕組みです。一方、「かこって検索」は対応Android端末で、今見ている画面からアプリを切り替えずに検索対象を選ぶ入口です。Google画像検索はWeb上で画像を探す検索画面で、そこに表示された画像からレンズ検索へ進むこともできます。

検索結果には、画像内の対象物の検索結果、類似画像、その画像または類似画像を掲載するWebサイト、場合によってはAIによる概要などが表示されます。

Android：カメラまたは保存写真から検索する

  1. GoogleアプリまたはChromeを開くGoogle公式は最新のGoogleアプリ、またはChromeを利用する方法を案内しています。
  2. 検索バーのGoogleレンズを開くカメラ検索または画像選択へ進みます。
  3. 写真を撮る / 保存画像を選ぶ目の前の物なら撮影、既存画像なら端末内の写真を選択します。
  4. 検索範囲を調整画像の一部だけ調べたい場合は選択枠を対象へ合わせます。
  5. 必要なら質問やキーワードを追加Google公式では検索結果を絞り込むため、画像について質問したりキーワードを追加できます。

保存写真をGoogleフォトから調べる場合は、写真を開き、メニューからGoogleレンズを選択する方法も公式に案内されています。

iPhone/iPad：Googleアプリ・Chrome・Safariを使い分ける

Google公式では、iPhone/iPadで保存画像を使って検索する入口としてGoogleアプリ、Chrome、Safariを案内しています。カメラや音声などを使って検索する場合はGoogleアプリの利用が案内されています。

  1. Googleアプリを使う場合検索バーのGoogleレンズから撮影または写真を選択します。
  2. Chromeを使う場合画像検索やWebページ上の画像からGoogleレンズへ進めます。
  3. 保存写真を使う場合写真選択から画像を指定し、検索範囲を調整します。
  4. 写真が表示されない場合iPhone設定 → アプリ → Google → 写真から、写真アクセスの「なし / 制限付き / フルアクセス」を確認します。

Googleアプリでは、検索結果に追加の語句を入れて絞り込む「検索に追加」が案内されています。アプリによって同じ機能名が表示されない場合があります。

Webサイト上の画像をGoogleレンズで検索する

Android/iPhoneとも、GoogleアプリやChromeでWebページ上の画像を長押しし、Googleレンズによる画像検索へ進めます。ChromeでWebサイトの画像を検索する場合、Google公式はGoogleをデフォルト検索エンジンに設定する必要があると案内しています。

商品写真やロゴなど、画像全体では別の要素が多すぎる場合は、選択範囲を目的の物だけへ狭めます。

対応Android端末なら「かこって検索」で画面をそのまま検索できる

Googleの「かこって検索」は、対応する一部Android端末で、ホームボタンまたはナビゲーションハンドルを長押しし、画面上の画像や文字を囲む・ハイライトする・タップするなどして検索する機能です。

全Android端末で利用できるわけではありません。Googleは対応端末、Googleアプリの更新、デフォルトのデジタルアシスタント設定、画面/アプリデータの利用権限などを利用条件として案内しています。

銀行・医療など機密性の高い一部アプリでは利用できない場合があります。

検索精度を上げるコツ：画像全体より対象を狭くする

Google公式も、より具体的な検索結果を得るには画像の選択領域を狭めるよう案内しています。特に商品型番、部品、ロゴ、植物の一部などを調べる場合に有効です。

  • 背景や別の商品を選択枠から外す
  • 小さい文字は近づいて撮影する
  • 型番・刻印が読める場合は文字検索も併用する
  • 最上位結果だけで商品・植物・場所を確定しない
  • 購入・安全・医療判断ではメーカーや公的な一次情報で再確認する

写真の文字をコピー・翻訳する

Googleレンズでは画像内のテキストを選択し、コピーや翻訳などの操作ができます。GoogleはレンズでGoogle翻訳が対応する言語への翻訳を案内しています。

住所・電話番号・荷物番号など、読み取った文字の種類によって追加操作が表示される場合があります。認識結果は誤ることがあるため、重要な番号は元画像と照合してください。

画像検索履歴：検索した画像が必ず保存されるわけではない

Googleは、画像を使った検索では画像検索技術で画像を処理すると説明しています。さらに、ログイン中に「画像検索履歴」の設定をオンにした場合、対象サービスで検索に使った画像をWebとアプリのアクティビティへ保存できます。

Google公式では画像検索履歴の設定はデフォルトでオフと案内されています。ただし、通常の検索アクティビティや履歴設定とは別の論点なので、機密情報や他人の個人情報が写る画像は必要部分だけに絞って検索するのが安全です。

よくある質問

AndroidではGoogleレンズ専用アプリが必要ですか？

Google公式はGoogleアプリやChromeからの利用を案内しており、Googleフォトから保存写真をレンズで検索する方法もあります。

iPhoneで保存写真をGoogleレンズ検索できますか？

できます。Googleアプリ、Chrome、Safariから保存画像を使う方法がGoogle公式に案内されています。

ChromeでWeb画像を長押ししてもGoogleレンズが出ません

Google公式では、ChromeでWebサイト上の画像を検索する場合はGoogleをデフォルト検索エンジンにする必要があると案内しています。Chromeの更新状況も確認してください。

かこって検索とGoogleレンズは同じですか？

関連する画像検索機能ですが入口が違います。かこって検索は対応Android端末で画面上の対象を選んで検索する機能です。

Googleレンズの検索結果は候補情報です。型番、真贋、健康、安全、法的判断など重要な結論は画像認識だけで確定せず、メーカー・公的機関などの一次情報で確認してください。
