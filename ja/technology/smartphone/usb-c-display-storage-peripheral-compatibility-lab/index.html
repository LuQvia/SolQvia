Phase109 · USB-C / Display / Storage / Peripherals

USB-Cは「端子が同じ」だけでは互換性を判断できない

映像・USB速度・充電・ストレージ・オーディオを、端末機能／ケーブル／ハブ／給電／周辺機器の条件に分けて確認します。

550端末・販売記録
—公式/現行一覧の有線映像候補
—Apple USB 3 10Gbps記録
—Samsung DeX現行一覧記録

条件を入力

重要

USB-C端子があってもDisplayPort映像、USB 3速度、PD/PPS、SSD/DAC動作は別機能です。

端末を選択してください。

診断結果

条件を選択して診断してください。

切り分け順

端末対応 → ケーブル規格 → ハブ/アダプタ → 給電 → 周辺機器 → OS/USB設定の順で確認します。

周辺機器の実機結果を整理

IMEI/EID/ICCID、電話番号、MACアドレス、シリアル番号、パスワード、認証コードは入力しないでください。報告は自動送信・自動公開されません。

このラボで分離するもの

  • USB-C端子の物理形状
  • DisplayPort / HDMI
  • USB 2 / USB 3データ速度
  • USB PD / PPS
  • 外付けSSD・USBメモリの認識と給電
  • USB-C DAC・マイク・Ethernet
  • Samsung DeX
