Phase86・モバイルWi-Fi深掘り

ポケットWi-Fiの5G SA/NSA・nBand比較｜SH-54C・X12・A503SH・Rakuten WiFi Pocket 5G

「5G対応」だけでは同じではなく、n79/n257やSA対応の有無でキャリア相性が変わります。

公式確認日: 2026-08-08実機検証: 未実施
判定の前提
Band相性
対応周波数の技術比較であり、他社回線の動作保証ではありません
実用可否
APN、VoLTE/IMS、専用SIM、位置情報サービス、登録住所などを別に評価
安全策
端末初期化やeSIM削除より先に、契約・回線開通・設定復旧経路を確認します

5G比較

機種5G BandSA/NSA特徴
SH-54Cn1 / n28 / n78 / n79 / n257SA/NSAドコモn79＋ミリ波n257まで対応
X12n3 / n28 / n41 / n77 / n78SA/NSAau/UQ向け、n79なし
A503SHn3 / n28 / n77 / n78SA設定あり/NSASoftBank n77中心、n79なし
Rakuten WiFi Pocket 5Gn77 / n785G Sub6楽天n77、n79/n257なし
Rakuten WiFi Pocket Platinumなし4GのみLTE専用

5Gにならない時

  1. 4G通信が成立するか確認
  2. 端末のnBandとエリアの5G周波数を確認
  3. SA/NSA設定を確認
  4. 契約プラン・SIM/eSIMが5G対象か確認
  5. ファームウェア更新

nBand一致だけでは不十分

n77が複数社で重なっていても、APN・LTEアンカーバンド・ネットワーク認証・SA/NSAの組み合わせが異なります。他社SIMの保証情報を優先してください。

判定上の注意

Band一致＝他社SIMで利用可能、ではありません。 SIM/eSIM形式、APN、ネットワーク認証、5G SA/NSA、契約プラン、利用先事業者の動作保証を分けて判断します。公式他社回線テストの○もサービス保証ではありません。
