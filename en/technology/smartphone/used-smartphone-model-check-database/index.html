Why the exact model should be checked first

Used phones with the same retail name can differ by carrier, open-market edition or region. SIM configuration, eSIM support, radio bands and local features such as FeliCa may therefore differ before the condition of the individual unit is considered. This database is the model-level gate before battery, cosmetic or ownership checks.

The displayed verification priority is not a safety score or a ranking. It indicates how much model-specific information still needs confirmation in the current SolQvia dataset. An item missing from a source table is not automatically converted into a hardware non-support claim.

What to check next

After the exact model is identified, review OS/security support and current repair routes, then assess the actual used unit for ownership locks, network restriction, battery condition, repair history, critical functions and seller warranty.

How to use this database

  1. Select the exact model number and original sales channel whenever possible.
  2. Choose the intended carrier and review technical fit plus unresolved checks.
  3. Review SIM/eSIM, FeliCa and evidence level.
  4. Once you have a specific used unit, run Phase115 with lock, restriction, battery, damage and warranty conditions.

Verification priority is not a quality or safety ranking. It only reflects how much model-level information still needs confirmation before purchase.
